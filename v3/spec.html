Build notes

  • iPad: FileMaker Go. The Take photo button becomes Insert from Device (Camera) into Steps::PhotoContainer. Downscale on insert to keep the file small.
  • TV: FileMaker WebDirect in a kiosk browser, or FileMaker Go on a device wired to the TV. Use an OnTimer script every 5 to 10 seconds to refresh the window and clear an expired spotlight.
  • Layouts: one fixed 1920 x 1080 layout per row count (1, 2 or 3 lines) plus one spotlight layout. The timer script picks the layout from the number of running lines and TVSession.
  • Which lines show: 3 or fewer running lines show all of them. With 4 or more, show TVSession::PinnedLines only. Idle lines collapse to a small strip.
  • Grid cell: for each line and station, show the Steps record where IsTVCheck = 1 (its photo and ShortText). Show the red flag if any step at that station has a Caution.
  • Reorder: up and down buttons that swap Order with the neighbor in the same station. No drag and drop, it is hard with gloves and in FileMaker Go.
  • Gloves: buttons 72 px or larger with 16 px gaps. Text contrast 7:1 or better. Amber for actions, red only for hazards, blue only for info.
